# Page frontmatter (articles & docs)

Full option list: see `vuepress-plume-config` → `references/frontmatter.md`. This page is the writing-oriented
cheat sheet.

## Minimal

```md
---
title: 文章标题
createTime: 2024/01/01 12:00:00
---
```

`title`, `createTime` and `permalink` are generated by `autoFrontmatter` when absent.

## Blog article

```md
---
title: 深入理解 Vue 3 响应式
createTime: 2024/05/01 10:00:00
tags: [vue, 源码]
cover: /images/vue3.png
coverStyle:
  layout: right
  ratio: '16:9'
  width: 240
sticky: 1
excerpt: 本文从 reactive 出发，逐步拆解依赖收集。
series: vue3-in-depth
seriesOrder: 2
---

正文……

<!-- more -->
```

| Key | Use |
| --- | --- |
| `sticky` | `true` or a number (higher = higher); only floats on list page 1 |
| `article: false` | hide from the article list |
| `cover` / `coverStyle` | list-page cover (absolute or remote URL only) |
| `excerpt: string` | custom summary (disables `<!-- more -->`) |
| `draft: true` | dev-only, excluded from production builds |
| `series` / `seriesOrder` / `seriesNav` | series membership and in-page cross links |
| `relatedPosts: false \| ['/a/']` | override recommendation output |
| `password` / `passwordHint` | page encryption |
| `copyright: 'CC-BY-4.0'` | per-page license |

## Docs page

```md
---
title: 主题配置
icon: mdi:cog-outline
createTime: 2024/03/02 18:07:03
outline: [2, 4]
---
```

`icon` also feeds the sidebar/navbar icon for that page; `outline` overrides the global outline level.

## Layout overrides

```md
---
pageLayout: doc     # 'doc'(default) | 'posts' | 'page' | 'custom' | 'home' | 'friends'
sidebar: false      # hide left sidebar, or a sidebar prefix string
aside: left         # move the right aside to the left
navbar: false
backToTop: false
comments: false
footer: false
---
```

## Per-heading outline

```md
## 标题 {data-outline="5"}

### 三级
#### 四级
##### 五级  <!-- 只有到 5 级的标题进入右侧目录 -->
```
