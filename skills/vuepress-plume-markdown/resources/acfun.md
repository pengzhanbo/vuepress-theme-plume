# AcFun

## Enable

```ts
markdown: { acfun: true }
```

## Syntax

```md
@[acfun](acid)
@[acfun width="100%" height="400px" ratio="16:9"](ac47431669)
```

| Prop | Type | Default |
| --- | --- | --- |
| `width` | `string` | `100%` |
| `height` | `string` | auto |
| `ratio` | `string` | `16:10` |

`ratio` only applies when `height` is not set.
