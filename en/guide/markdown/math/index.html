Overview

The theme has built-in support for mathematical formulas.

This feature is powered by @vuepress/plugin-markdown-math. You can choose to render mathematical formulas in markdown using the following methods:

  • katex (default)
  • mathjax
.vuepress/config.ts
export default defineUserConfig({
  theme: plumeTheme({
    markdown: {
      math: {
        type: 'katex', // 'katex' | 'mathjax'
        // ... Other configuration options
      }
    },
  })
})

When you choose to use mathjax, you also need to install the dependency by running the following command:

npm
npm i @mathjax/src
pnpm
pnpm add @mathjax/src
yarn
yarn add @mathjax/src

Syntax

Inline Syntax

Use $ to wrap mathematical formulas (i.e., write the mathematical formula between two $ symbols)

This page's examples require the demo syntax to be enabled first

The ::: demo syntax is disabled by default. When it is not enabled, the md code blocks below are rendered as plain code blocks and no rendered output is shown.

.vuepress/config.ts
import { defineUserConfig } from 'vuepress'
import { plumeTheme } from 'vuepress-theme-plume'

export default defineUserConfig({
  theme: plumeTheme({
    markdown: {
      demo: true, 
    },
  }),
})

Supported TeX / KaTeX Commands

Configuration Options

Name:type

Optional

Type:'katex' | 'mathjax'

Default:'katex'

Package used to render TeX\TeXTE​X content.

  • 'katex': Use KaTeX
  • 'mathjax': Use MathJax

Name:delimiters

Optional

Type:'brackets' | 'dollars' | 'all'

Default:'dollars'

Enabled math delimiter syntax.

  • "brackets": Use \(...\) for inline math and \[...\] for display mode math (LaTeX style)
  • "dollars": Use $...$ for inline math and $$...$$ for display mode math (common Markdown style)
  • "all": Enable both bracket and dollar sign syntax

Using KaTeX

When using KaTeX, any other options will be passed to KaTeX as KatexOptions. For all available options, refer to the KaTeX documentation.

Additionally, 2 special options are supported:

Name:copy

Optional

Type:boolean

Whether to enable the copy extension.

Name:mhchem

Optional

Type:boolean

Whether to enable the mhchem extension.

Using MathJax

When using MathJax, you can set:

Optional

Type:object

Options passed to the TeX input parser.

Name:output

Optional

Type:'svg' | 'chtml'

Default:'svg'

Output format, either SVG or Common HTML.

Name:chtml

Optional

Type:object

Options passed to the Common HTML output parser.

Name:svg

Optional

Type:object

Options passed to the SVG output parser.
