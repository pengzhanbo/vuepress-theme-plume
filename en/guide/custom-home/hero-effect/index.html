Overview

For most websites, a visually stunning homepage hero section can more easily attract users to stay. However, achieving visual appeal often requires complex technical effort and a touch of creative inspiration.

The theme comes with a series of visually impressive background effects built into the Hero section of the homepage, which can be easily applied to your site through simple configuration:

---
pageLayout: home
home: true
config:
 -
    type: hero
    full: true
    effect: tint-plate
    effectConfig:
      key: value
---

Only when type: hero is set will the theme apply the effect specified in effect.

The effect property supports the following values:

  • tint-plate
  • prism
  • pixel-blast
  • hyper-speed
  • liquid-ether
  • dot-grid
  • iridescence
  • orb
  • beams
  • lightning
  • dark-veil

The effectConfig should be configured according to the selected effect. In most cases, you don’t need to configure it—the theme will automatically apply preset configurations.

Note

The built-in effects are based on the excellent open-source project vue-bits, whose code has been adapted and integrated into the theme under the MIT license.

Force Dark Mode

Most background effects perform better in dark mode, so it is recommended to enable dark mode for the best experience.

However, for documentation pages, you may prefer light mode. Therefore, the theme provides a forceDark option in the hero section, which forces the homepage into dark mode without affecting the color mode of other pages.

---
pageLayout: home
home: true
config:
 -
    type: hero
    full: true
    forceDark: true
    effect: lightning
---

Dynamic Background Effects

Important

Some effects may depend on three, gsap, or ogl. You need to manually install the corresponding dependencies based on the effect you choose.

The theme loads these effects on-demand, so there is no need to worry about increasing the final bundle size.

tint-plate

Effect Preview

Usage

---
pageLayout: home
home: true
config:
 -
    type: hero
    full: true
    effect: tint-plate
---

Configuration

effectConfig is used to configure RGB values:

  • When configured as a single value, it sets the same value for red, green, and blue channels (range: 0–255). Example: 210.
  • When configured as three values, it sets different values for red, green, and blue channels (range: 0–255). Example: 210,210,210.
  • When configured as TintPlate, it allows more flexible control over each color value and its corresponding offset.
  • It can also be configured as { light: TintPlate, dark: TintPlate } to use different color values in light mode and dark mode.
interface TintPlate {
  r: { value: number, offset: number } // value is the color value, offset is the offset
  g: { value: number, offset: number }
  b: { value: number, offset: number }
}

Example：

Single value
---
pageLayout: home
home: true
config:
 -
    type: hero
    full: true
    effect: tint-plate
    effectConfig: 210
---
Three values
---
pageLayout: home
home: true
config:
 -
    type: hero
    full: true
    effect: tint-plate
    effectConfig: 210,210,210
---
TintPlate
---
pageLayout: home
home: true
config:
 -
    type: hero
    full: true
    effect: tint-plate
    effectConfig:
      r:
        value: 210
        offset: 0
      g:
        value: 210
        offset: 0
      b:
        value: 210
        offset: 0
---

Info

To help users easily configure visually appealing and personalized backgrounds, the theme also provides a Homepage Hero Tint Plate Configuration Tool. You can use this tool for visual configuration and generate configuration content that can be directly copied into your own project.

prism

Effect Preview

Install dependencies

npm
npm i ogl
pnpm
pnpm add ogl
yarn
yarn add ogl

Usage

---
pageLayout: home
home: true
config:
 -
    type: hero
    full: true
    effect: prism
---

Configuration

Name:height

Optional

Type:number

Default:3.5

Apex height of the prism (world units)

Name:baseWidth

Optional

Type:number

Default:5.5

Total base width across X/Z (world units).

Name:animationType

Optional

Type:'rotate' | 'hover' | '3drotate'

Default:'rotate'

Animation mode: shader wobble, pointer hover tilt, or full 3D rotation.

Name:glow

Optional

Type:number

Default:1

Glow/bleed intensity multiplier.

Name:offset

Optional

Type:{ x?: number, y?: number }

Default:{ x: 0, y: 0 }

Pixel offset within the canvas (x→right, y→down).

Name:noise

Optional

Type:number

Default:0

Film-grain noise amount added to final color (0 disables).

Name:transparent

Optional

Type:boolean

Whether the canvas has an alpha channel (transparent background).

Name:scale

Optional

Type:number

Default:3.6

Overall screen-space scale of the prism (bigger = larger).

Name:hueShift

Optional

Type:number

Default:0

Hue rotation (radians) applied to final color.

Name:colorFrequency

Optional

Type:number

Default:1

Frequency of internal sine bands controlling color variation.

Name:hoverStrength

Optional

Type:number

Default:2

Sensitivity of hover tilt (pitch/yaw amplitude).

Name:inertia

Optional

Type:number

Default:0.05

Easing factor for hover (0..1, higher = snappier).

Name:bloom

Optional

Type:number

Default:1

Extra bloom factor layered on top of glow.

Name:suspendWhenOffscreen

Optional

Type:boolean

Pause rendering when the element is not in the viewport.

Name:timeScale

Optional

Type:number

Default:0.5

Global time multiplier for animations (0=frozen, 1=normal).

Example:

---
pageLayout: home
home: true
config:
 -
    type: hero
    full: true
    effect: prism
    effectConfig:
      height: 3.5,
      baseWidth: 5.5
      animationType: rotate
      glow: 1
      offset:
        x: 0
        y: 0
      noise: 0
      transparent: true
      scale: 3.6
      hueShift: 0
      colorFrequency: 1
      hoverStrength: 2
      inertia: 0.05
      bloom: 1
      suspendWhenOffscreen: true
      timeScale: 0.5
---

liquid-ether

Effect Preview

Install dependencies

npm
npm i three
pnpm
pnpm add three
yarn
yarn add three

Usage

---
pageLayout: home
home: true
config:
 -
    type: hero
    full: true
    effect: liquid-ether
---

Configuration

Name:mouseForce

Optional

Type:number

Default:20

Strength multiplier applied to mouse / touch movement when injecting velocity.

Name:cursorSize

Optional

Type:number

Default:100

Radius (in pixels at base resolution) of the force brush.

Name:isViscous

Optional

Type:boolean

Toggle iterative viscosity solve (smoother, thicker motion when enabled).

Name:viscous

Optional

Type:number

Default:30

Viscosity coefficient used when isViscous is true.

Name:iterationsViscous

Optional

Type:number

Default:32

Number of Gauss-Seidel iterations for viscosity (higher = smoother, slower).

Name:iterationsPoisson

Optional

Type:number

Default:32

Number of pressure Poisson iterations to enforce incompressibility.

Name:dt

Optional

Type:number

Default:0.014

Fixed simulation timestep used inside the advection / diffusion passes.

Name:BFECC

Optional

Type:boolean

Enable BFECC advection (error-compensated) for crisper flow; disable for slight performance gain.

Name:resolution

Optional

Type:number

Default:0.5

Simulation texture scale relative to canvas size (lower = better performance, more blur).

Name:isBounce

Optional

Type:boolean

If true, shows bounce boundaries (velocity clamped at edges).

Name:colors

Optional

Type:string[]

Default:['#5227FF', '#FF9FFC', '#B19EEF']

Array of hex color stops used to build the velocity-to-color palette.

Name:autoDemo

Optional

Type:boolean

Enable idle auto-driving of the pointer when no user interaction.

Name:autoSpeed

Optional

Type:number

Default:0.5

Speed (normalized units/sec) for auto pointer motion.

Name:autoIntensity

Optional

Type:number

Default:2.2

Multiplier applied to velocity delta while in auto mode.

Name:takeoverDuration

Optional

Type:number

Default:2.5

Seconds to interpolate from auto pointer to real cursor when user moves mouse.

Name:autoResumeDelay

Optional

Type:number

Default:1000

Milliseconds of inactivity before auto mode resumes.

Name:autoRampDuration

Optional

Type:number

Default:0.6

Seconds to ramp auto movement speed from 0 to full after activation.

Name:className

Optional

Type:string

Custom class name to apply to the container element

Name:style

Optional

Type:CSSProperties

Custom inline styles to apply to the container element

Example：

---
pageLayout: home
home: true

 -
    type: hero
    full: true

      isViscous: false
      viscous: 30
      iterationsViscous: 32
      iterationsPoisson: 32
      dt: 0.014
      BFECC: true
      resolution: 0.5
      isBounce: false
      colors: [#5227FF, #FF9FFC, #B19EEF]

      autoIntensity: 2.2
