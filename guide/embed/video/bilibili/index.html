概述

主题提供了嵌入 Bilibili 视频的功能。

该功能由 vuepress-plugin-md-power 提供支持。

配置

该功能默认不启用。你需要在主题配置中开启。

.vuepress/config.ts
export default defineUserConfig({
  theme: plumeTheme({
    markdown: {
      bilibili: true, 
    },
  })
})

语法

简单的语法：

@[bilibili](bvid)

带分P 的视频，在 bilibili 后跟随 p1、p2、p3 等选项

@[bilibili p1](aid cid)

更多选项：

@[bilibili p1 autoplay time="0" width="100%" height="400px" ratio="16:9"](bvid aid cid)

选项说明：

Name:bvid

可选

Type:string

视频 BV ID，以 BV 开头

Name:aid

可选

Type:string

视频 AID。与 cid 配合使用时可省略 bvid

Name:cid

可选

Type:string

视频 CID

Name:p1

可选

Type:string

分 P 标记，裸写即可（如 @[bilibili p1](…)），支持 p1 / p2 / …

Name:autoplay

可选

Type:boolean

是否自动播放

Name:time

可选

Type:number | string

视频开始播放时间点，单位为秒，也可以使用 mm:ss 或 hh:mm:ss 格式

Name:width

可选

Type:string

默认值:100%

视频宽度

Name:height

可选

Type:string

视频高度。未指定时按自动高度处理

Name:ratio

可选

Type:string

默认值:16:9

视频比例

对于分P的视频，可以省略传入 bvid，但需要传入 aid 和 cid
